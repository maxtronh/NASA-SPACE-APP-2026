## 1. Architectural Vision and Core Principles

"Flame in Freefall" is an advanced Scientific Intelligence (SI) and analytics platform designed to unlock decades of microgravity combustion research conducted by NASA Glenn Research Center (GRC), the Space Shuttle missions, and the International Space Station (ISS) Combustion Integrated Rack (CIR).

### 1.1 Core Architectural Principles
1. **Scientific Veracity & Anti-Hallucination**:
   - Microgravity combustion is governed by delicate physics (e.g., balance between molecular diffusion, chemical kinetics, and radiative heat loss).
   - Inferences and answers generated by the platform must be grounded in verified flight data and peer-reviewed NASA Technical Publications.
   - When evidence is absent, the system must explicitly abstain rather than fabricate plausible-sounding answers.
2. **Strict Null-Preservation (Non-Zero Rule)**:
   - In combustion physics, an observation of $0.0\text{ mm}$ for extinction diameter means the droplet burned entirely to extinction at zero radius, whereas `NULL` means the extinction diameter was unobservable or unrecorded.
   - The database, ingestion pipeline, API, and UI strictly preserve `NULL` values and never coerce missing data to `0.0`.
3. **Cryptographic Provenance**:
   - Every data point links back to its authoritative source URL (NTRS / PSI), retrieval timestamp, HTTP ETag, and raw payload SHA-256 checksum.
4. **Resilient Dual-Tier Deployment**:
   - Production & Demo: Orchestrated via Docker Compose with PostgreSQL 16 + `pgvector`, FastAPI backend, and Next.js frontend.
   - Development & Offline Testing: In-process SQLite + numpy vector cosine fallback ensuring 100% of unit and integration tests run deterministically even if Docker Desktop is offline.

## 3. Database Schema Specification (PostgreSQL 16 + pgvector)

### 3.1 Table: `investigations`
Primary registry of NASA flight and ground campaigns.

| Column | Data Type | Constraints | Description |
|---|---|---|---|
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | Unique investigation identifier |
| `slug` | VARCHAR(100) | UNIQUE, NOT NULL | URL-safe slug (e.g. `flex-droplet-burning`) |
| `title` | TEXT | NOT NULL | Official NASA publication / project title |
| `short_name` | VARCHAR(50) | NOT NULL | Compact name (e.g. "FLEX Droplet Extinction") |
| `project_acronym` | VARCHAR(50) | NOT NULL | NASA acronym (e.g. "FLEX", "ACME", "BASS-II", "SoFIE") |
| `facility` | VARCHAR(100) | NOT NULL | Platform/rig (e.g. "Combustion Integrated Rack (CIR)", "MSG") |
| `combustion_regime` | VARCHAR(50) | NOT NULL | Regime: `droplet_combustion`, `laminar_diffusion`, `solid_spread`, `flame_ball`, `cool_flame` |
| `fuel_type` | VARCHAR(100) | NOT NULL | Primary fuel (e.g. "Methanol", "n-Heptane", "PMMA", "Ethylene") |
| `oxidizer_type` | VARCHAR(100) | NOT NULL | Oxidizer mix (e.g. "Air", "Oxygen/Nitrogen Blend") |
| `diluents` | VARCHAR(100) | NULL | Inert gases (e.g. "Nitrogen", "Carbon Dioxide", "Helium") |
| `gravity_level` | VARCHAR(50) | NOT NULL | Gravity state (e.g. "microgravity (~10^-6 g)", "normal_gravity (1 g)") |
| `start_date` | DATE | NULL | Operational start date |
| `end_date` | DATE | NULL | Operational conclusion date |
| `principal_investigators` | JSONB | NOT NULL | Array of `{"name": str, "affiliation": str, "role": str}` |
| `summary` | TEXT | NOT NULL | Comprehensive scientific abstract |
| `objectives` | TEXT | NOT NULL | Formal research hypotheses & objectives |
| `apparatus_description` | TEXT | NULL | Hardware description, chamber volume, optical diagnostics |
| `data_completeness_index` | FLOAT | NOT NULL, DEFAULT 0.0 | Calculated completeness metric (0.0 to 100.0%) |
| `nasa_source_url` | TEXT | NOT NULL | Persistent link to NTRS report or PSI collection |
| `source_repository` | VARCHAR(50) | NOT NULL | Source name (`NASA NTRS`, `NASA PSI`) |
| `created_at` | TIMESTAMPTZ | DEFAULT NOW() | Record creation timestamp |
| `updated_at` | TIMESTAMPTZ | DEFAULT NOW() | Record last update timestamp |

### 3.2 Table: `test_runs`
Individual flight experiment trials, droplet burns, or solid sample flammability runs.

| Column | Data Type | Constraints | Description |
|---|---|---|---|
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | Unique trial identifier |
| `investigation_id` | UUID | REFERENCES investigations(id) ON DELETE CASCADE | Parent investigation foreign key |
| `run_identifier` | VARCHAR(100) | NOT NULL | Official trial ID (e.g. "FLEX-001", "BASS-II-Rod-04") |
| `run_date` | TIMESTAMPTZ | NULL | Trial execution timestamp |
| `fuel_phase` | VARCHAR(50) | NOT NULL | Phase: `liquid_droplet`, `solid_sample`, `gas_jet` |
| `chamber_pressure_kpa` | FLOAT | NULL | Ambient pressure in kilopascals (NULL if unmeasured) |
| `ambient_temperature_k` | FLOAT | NULL | Ambient temperature in Kelvin (NULL if unmeasured) |
| `oxygen_percentage` | FLOAT | NULL | O2 volume percentage (0.0 to 100.0) |
| `fuel_flow_rate_sccm` | FLOAT | NULL | Gaseous fuel flow rate (sccm; NULL if non-gaseous) |
| `droplet_initial_diameter_mm` | FLOAT | NULL | Initial droplet diameter $d_0$ in mm (NULL if non-droplet) |
| `burn_duration_s` | FLOAT | NULL | Combustion duration in seconds |
| `extinction_type` | VARCHAR(100) | NULL | Mode: `radiative_extinction`, `blowoff`, `disruption`, `completion` |
| `burning_rate_constant_k_mm2_s` | FLOAT | NULL | Droplet burning constant $K$ in $mm^2/s$ ($d^2 = d_0^2 - Kt$) |
| `flame_spread_rate_mm_s` | FLOAT | NULL | Solid fuel flame spread velocity $V_f$ in $mm/s$ |
| `raw_parameters` | JSONB | NOT NULL | Unaltered original parameter dictionary from NASA raw record |
| `si_normalized_parameters` | JSONB | NOT NULL | Dual-unit SI normalized parameters dictionary |

### 3.3 Table: `measurements`
Time-series and discrete physical observations tied to test runs.

| Column | Data Type | Constraints | Description |
|---|---|---|---|
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | Unique observation identifier |
| `test_run_id` | UUID | REFERENCES test_runs(id) ON DELETE CASCADE | Test run foreign key |
| `investigation_id` | UUID | REFERENCES investigations(id) ON DELETE CASCADE | Investigation foreign key |
| `metric_name` | VARCHAR(100) | NOT NULL | Parameter name (e.g. `droplet_diameter_squared`, `radiant_flux`) |
| `time_seconds` | FLOAT | NULL | Elapsed time since ignition $t=0$ (NULL for scalar totals) |
| `value_si` | FLOAT | NULL | Normalized numerical SI value (NULL if unmeasured) |
| `unit_si` | VARCHAR(50) | NOT NULL | SI unit symbol (e.g. `m`, `m^2/s`, `Pa`, `K`, `W/m^2`) |
| `original_value` | VARCHAR(50) | NULL | Original string from NASA publication (e.g. "0.52", "–") |
| `original_unit` | VARCHAR(50) | NULL | Raw unit string (e.g. `mm2/s`, `mmHg`, `psia`) |
| `conversion_method` | VARCHAR(100) | NOT NULL | Formula used (e.g. `val * 1e-6`, `P_mmHg * 133.322`) |
| `validation_status` | VARCHAR(50) | NOT NULL | `VALID`, `EXTINCTION_UNOBSERVED`, `DISRUPTION`, `MISSING_DATA` |
| `sensor_type` | VARCHAR(100) | NULL | Diagnostic sensor (e.g. "Color Camera 30fps", "SiC Fiber") |

### 3.4 Table: `vector_embeddings`
Dense vector embeddings supporting hybrid search and Scientific Intelligence.

| Column | Data Type | Constraints | Description |
|---|---|---|---|
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | Vector entry identifier |
| `entity_type` | VARCHAR(50) | NOT NULL | Entity type (`investigation_summary`, `test_run_profile`, `literature`) |
| `entity_id` | UUID | NOT NULL | Target entity foreign key |
| `chunk_index` | INT | NOT NULL DEFAULT 0 | Split chunk index |
| `chunk_text` | TEXT | NOT NULL | Text passage vectorized |
| `embedding` | VECTOR(384) | NOT NULL | 384-dimensional dense vector (`BAAI/bge-small-en-v1.5`) |
| `metadata_json` | JSONB | NOT NULL | Faceting metadata: fuel, regime, facility, pressure, year |

**Indices**:
```sql
CREATE INDEX idx_vector_embeddings_hnsw ON vector_embeddings 
USING hnsw (embedding vector_cosine_ops) WITH (m = 16, ef_construction = 64);

CREATE INDEX idx_vector_chunk_fts ON vector_embeddings 
USING gin(to_tsvector('english', chunk_text));
```

### 3.5 Table: `provenance_records`
Immutable cryptographic audit log.

| Column | Data Type | Constraints | Description |
|---|---|---|---|
| `id` | UUID | PRIMARY KEY, DEFAULT gen_random_uuid() | Audit record identifier |
| `investigation_id` | UUID | REFERENCES investigations(id) ON DELETE CASCADE | Associated investigation |
| `source_url` | TEXT | NOT NULL | Exact URL fetched from NASA |
| `retrieval_timestamp` | TIMESTAMPTZ | NOT NULL | ISO-8601 UTC timestamp of fetch |
| `sha256_checksum` | VARCHAR(64) | NOT NULL | SHA-256 hash of raw byte payload |
| `http_etag` | VARCHAR(100) | NULL | Upstream HTTP ETag header |
| `byte_size` | BIGINT | NOT NULL | Exact raw byte size |
| `parser_module` | VARCHAR(100) | NOT NULL | Module name (e.g. `ingestion.parsers.flex`) |
| `parser_version` | VARCHAR(20) | NOT NULL | Parser semantic version (e.g. `1.0.0`) |
| `validation_status` | VARCHAR(50) | NOT NULL | Integrity status (`VALIDATED`, `REJECTED`) |

## 4. REST API Endpoint Inventory

All endpoints are versioned under `/api/v1` and generate automated OpenAPI documentation at `/docs`.

| Route | Method | Purpose | Input / Body | Output Model |
|---|---|---|---|---|
| `/api/v1/health` | GET | System, database, and vector liveness | None | `HealthResponse` |

| `/api/v1/analytics/missing-data-analysis` | GET | Completeness matrix across parameters | None | `MissingDataAnalysisResponse` |

## 6. Frontend Structure & Visual Components

The Next.js 15 frontend is organized around scientific discovery workflows:

- **Global Navigation Bar (`Navbar.tsx`)**: Real-time status badge (connected to `/api/v1/health`), quick search input, navigation links to Explorer, Comparison, SI Assistant, and Analytics.
- **Main Dashboard (`app/page.tsx`)**: High-level telemetry (total flight investigations, total test runs, combustion regimes distribution donut chart via Recharts).
- **Investigation Explorer (`app/investigations/page.tsx`)**:
  - Filter sidebar: multi-select for combustion regime, fuel type, facility, and gravity level.
  - Search bar with 300ms debounce.
  - Card grid / table toggle displaying Data Completeness Index ($DCI$) badge and provenance indicator.
- **Investigation Detail Profile (`app/investigations/[id]/page.tsx`)**:
  - Deep dive tabs: Overview, Apparatus & Diagnostics, Test Runs Table, Interactive Visualizer, Literature, and Cryptographic Provenance Card.
- **Interactive Visualizers (`components/visualizations/`)**:
  - `DropletD2Plot.tsx`: Plotly $d^2(t)$ regression chart displaying initial diameter $d_0$, slope $K$ ($mm^2/s$), and experimental time points.
  - `CompletenessHeatmap.tsx`: Heatmap of investigations vs. physical measurement axes.
- **Comparison Workspace (`app/compare/page.tsx`)**: Side-by-side comparative grid showing parameter deltas, highlighting condition non-equivalence (e.g. pressure difference, oxidizer dilution).
- **Evidence-Grounded SI Chat (`app/intelligence/page.tsx`)**: Conversational interface with citation badges linking to NTRS publications, certainty score meters, and explicit abstention alerts.
